BUILD NOTES

This project is ready to import/build in Android Studio.

Toolchain:
- compileSdkVersion 30
- minSdkVersion 19
- targetSdkVersion 19
- Android Gradle Plugin 7.4.2
- Gradle 7.5
- Java 7 source/target compatibility

Android Studio may regenerate/download the Gradle wrapper on first sync if the wrapper JAR is absent.
For command-line builds, install Gradle 7.5 locally or let Android Studio perform the first sync, then use:
    gradle assembleDebug

Debug APK:
    app/build/outputs/apk/debug/app-debug.apk
